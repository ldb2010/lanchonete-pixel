# Lanchonete Pixel

Site de demonstração da apresentação sobre Design Responsivo.

| Arquivo | O que mostra |
|---|---|
| `index.html` | Site quebrado: sem meta viewport e com larguras fixas (QR code 1) |
| `viewport.html` | Conserto 1: com meta viewport, mas colunas ainda largas |
| `final.html` | Site consertado (para a revelação no celular, tablet e laptop) |
| `bug.html` | Caça ao bug: o botão "Fazer pedido" sai da tela abaixo de 360px (QR code 2) |
